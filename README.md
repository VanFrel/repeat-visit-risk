# Прогноз риска повторного обращения после ремонта автомобиля, метрики качества прогноза и выбор порога усиленного контроля

### Аннотация
Рассмотрена задача сервиса автомобилей — в момент закрытия заказ-наряда оценить вероятность того, что клиент вернётся с той же неисправностью в течение 30 дней, и направить рискованные автомобили на усиленный контроль. Исследован массив из 3 000 закрытых заказ-нарядов с долей повторных обращений 33,8 %. Логистическая регрессия и случайный лес сравнены на 100 случайных разбиениях выборки. Для каждой метрики качества (доля верных ответов, полнота, точность, F1, ROC-AUC, оценка Брайера) показан её практический смысл. Логистическая регрессия оказалась немного, но устойчиво точнее — ROC-AUC 0,920 против 0,914 (лучше в 97 запусках из 100). Главный фактор повторного обращения — неподтверждённый первоначальный диагноз. При пороге 0,35 на проверку направляются 38 автомобилей из 100, и среди них оказывается 84 % будущих повторных обращений.
